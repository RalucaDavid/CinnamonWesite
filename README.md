## 📚 CinnamonEdu.ro

CinnamonEdu.ro is a modern, trilingual educational site built with a clean UX/UI design. It focuses on the health benefits of cinnamon and features dynamic content switching between **Romanian, English and German**.

---

## 💻 Technologies

| Category | Technology |
| :--- | :--- |
| **Framework** | **React** (Functional Components) |
| **Tooling** | **Vite** |
| **Styling** | **Sass (SCSS)** |
| **Language** | **JavaScript / JSX** |
| **Content** | Trilingual data handled by **Dictionaries (JS Objects)** |

---

## 🚀 Quick Setup

### Prerequisites

You need **Node.js (16+)** and **npm** installed.

### 1. Clone & Navigate

```bash
git clone https://github.com/RalucaDavid/CinnamonWesite.git
cd cinnamon-website
```

### 2. Install Dependencies

```bash
npm install
npm install -D sass
```

### 3. Run Development Server

The app will run at http://localhost:5173.

```bash
npm run dev
```
